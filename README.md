# Portal Central Docente

Base profissional em Next.js App Router e Supabase SSR.

## Implantação
1. Copie `.env.example` para `.env.local`.
2. Preencha a chave publicável do Supabase.
3. Execute `supabase/schema.sql`.
4. Rode `npm install` e `npm run build`.
5. Envie o conteúdo desta pasta para a raiz do GitHub e importe na Vercel.
